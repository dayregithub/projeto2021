Arquivador para Windows

Crie automaticamente as pastas dos orçamentos no seu computador, com o PDF e uma cópia editável pelo painel.

Baixar aplicativo · Windows 10/11, 64 bits

  1. Baixe o ZIP e extraia os arquivos.
  2. Abra PapeledMakerArquivador.exe. Ele instala para seu usuário e abre uma tela com o código de vinculação.
  3. Copie o código. No painel, abra Marca da empresa → Arquivamento no Windows, cole o código e clique em Vincular aplicativo.
  4. Permita o acesso à rede local se o navegador solicitar.
  5. No orçamento, clique em Salvar, arquivar e fechar.

O destino inicial será DocumentosPapeled MakerOrçamentosNÚMERO-DO-ORÇAMENTO. Não é preciso escolher uma pasta. O aplicativo encontra a pasta Documentos do seu usuário, inclusive se estiver no OneDrive.

Alterar o destino

No mesmo local do painel, clique em Verificar conexão, edite Caminho de salvamento no Windows e confirme em Alterar caminho de salvamento. A nova pasta é criada automaticamente; arquivos anteriores permanecem onde estavam.

Uso diário

O aplicativo inicia com o Windows. Se ele não responder, abra Papeled Maker Arquivador no menu Iniciar. O painel só fecha o orçamento após receber a confirmação da gravação. Repetir o arquivamento atualiza os arquivos da mesma pasta. O PDF pode ser enviado ao cliente; o JSON inclui dados pessoais e custos internos.

Remover

Use Menu Iniciar → Papeled Maker → Desinstalar arquivador. Os orçamentos são preservados. Desvincule também no painel. Há um atalho separado para parar temporariamente.

O instalador ainda não tem assinatura digital e pode gerar aviso do Windows. Confira a origem do download e siga as regras do seu computador. Não é necessário desativar o antivírus.

Compilado para Windows x64; testes de gravação e integração executados em Linux. A instalação e a autorização do navegador precisam ser verificadas no seu Windows.
