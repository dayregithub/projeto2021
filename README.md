# Papeled Maker

Vitrine conceitual em português para corte a laser e impressão 3D, com ilustrações SVG e personalizador visual.

## Desenvolvimento

Requer Node.js 20.19+ ou 22.12+. No diretório `/workspace/projeto2021`:

```sh
npm ci --cache /tmp/forma-npm-cache
npm run dev
```

Produção: `npm run build`. Os arquivos estáticos ficam em `dist/`.

## Personalização

Marca e textos: `index.html`; catálogo e ilustrações: `main.js`; cores e layout: `style.css`. Os seis produtos são exemplos.
