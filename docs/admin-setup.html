Conectar seu espaço maker

A prévia local já permite testar o painel. Para compartilhar produtos e receber estatísticas e pedidos de todos os visitantes, siga estes passos.

  1. Crie sua conta no Supabase e um projeto. Guarde a senha do banco em local seguro; não a envie no chat.
  2. Abra o SQL Editor do projeto. Copie o conteúdo do arquivo de instalação do painel e execute uma vez no projeto novo. O arquivo reúne as migrações 001 e 002 e cria também o armazenamento privado das cópias baixadas. Se já instalou a versão anterior, execute somente a migração 002 fornecida pelo responsável pela publicação.
  3. Em Authentication → Users, crie sua conta de administrador com e-mail e senha. Desative cadastros públicos nas configurações de Authentication. Copie o ID do usuário criado.
  4. No SQL Editor execute insert into public.admin_users(id) values ('ID-DO-SEU-USUARIO'); substituindo pelo ID real. Somente contas nessa lista podem administrar produtos, ler pedidos e consultar estatísticas.
  5. Em Project Settings → API, copie a URL do projeto e a chave pública anon ou publishable. Informe esses dois dados ao responsável pela publicação para preencher public/platform-config.json no repositório e publicar novamente. Essas duas informações são públicas. Nunca envie senha do banco, chave secret ou service_role.
  6. Depois da publicação, entre no painel com o e-mail e senha da conta criada. Cadastre um produto de teste, publique e abra o site em outro navegador. Autorize as estatísticas, faça um download e envie um orçamento para confirmar o recebimento.

Assistente de IA (opcional)

A função supabase/functions/maker-assistant precisa ser publicada no seu Supabase. A chave OPENAI_API_KEY deve ser cadastrada apenas nos Secrets da função. O assistente usa a API da OpenAI e pode gerar custos. Ela só atende administradores autenticados, fornece sugestões e não publica automaticamente.

O que as estatísticas significam

Acessos contam carregamentos da página com autorização. Downloads contam acionamentos do navegador, sem confirmar que o arquivo foi salvo. Não há dados anteriores à ativação, nem contagem de pessoas únicas. Pedidos aparecem somente depois do envio explícito pelo formulário. As estatísticas públicas podem incluir automação; não são uma auditoria de tráfego.
